# MAAS Teaching Agent

AI-powered teaching assistant for the Marketing Automation & Agentic Systems (MAAS) 24-session MBA curriculum at IIM Kozhikode.

## Quick Start

### Invoke the Agent
```powershell
MAAS-Teach: Generate teaching script for Session 5 on Consumer Behavior in AI-Driven Marketing
MAAS-Teach: Generate discussion questions for [case name]
MAAS-Teach: Design session activity for [topic/week]
MAAS-Teach: Create assignment on [topic] with grading rubric
```

### What It Generates
- **Teaching Scripts**: Complete 90-minute classroom plans with timing
- **Case Discussions**: Structured discussion questions (8-10 per case)
- **Session Activities**: Engaging activities for 30+ MBA students
- **Assignments**: Full specifications with 6-8 criteria grading rubrics
